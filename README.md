# 微流 WeFlow AI

一个面向微信公众号内容团队的本地优先 AI 工作台。将包含 Word 新闻稿和配图的 ZIP 导入后，可以完成素材解析、模板推荐、结构化成稿、按区块精准修改、模拟预览与 HTML 导出。

## 已实现

- 多任务创建、阶段状态和自动保存
- ZIP 内 `.docx` / `.txt` 正文解析
- ZIP 配图提取；没有独立配图时自动提取 Word 内嵌图片
- DeepSeek 驱动的 5 套模板推荐与文章生成
- 8 套自有微信兼容模板
- 结构化文章区块和公众号手机尺寸模拟预览
- 点击区块后锁定范围进行 AI 精修
- 修改记录和文章版本留存
- 复制微信富文本、导出 HTML
- 一键压缩并上传正文图片/封面、创建微信公众号草稿、打开公众号后台
- 基于历史完成项目的本地轻量 RAG，复用模板及修改偏好
- DeepSeek 不可用时的规则降级方案

## 启动

```bash
npm install
npm run dev
```

访问 <http://localhost:3000>。

如需从公网 IP 或域名远程访问开发服务器，请运行 `npm run dev -- -H 0.0.0.0`，并在 `.env.local` 中设置 `ALLOWED_DEV_ORIGINS`（多个来源用英文逗号分隔）。当前已默认允许 `43.139.202.189`。

环境变量参考 `.env.example`。真实密钥请放在 `.env.local`，该文件已被 `.gitignore` 排除。

ZIP 默认上限为 1GB（`1024MB`），可通过 `MAX_UPLOAD_MB` 调整。当前 MVP 会将 ZIP 读入服务端内存，超大文件可能占用数倍内存；正式部署必须改为对象存储分片直传和后台异步解压。

要启用微信公众号草稿同步，请在 `.env.local` 配置：

```bash
WECHAT_APP_ID=公众号AppID
WECHAT_APP_SECRET=公众号AppSecret
```

公众号需拥有草稿及素材接口权限，并在公众平台配置服务器出口 IP 白名单。同步成功后系统会打开公众号后台；微信没有公开的指定草稿编辑/预览深链，因此仍需在草稿箱中打开文章并点击预览。

## 建议的素材格式

```text
新闻稿.zip
├── 新闻稿.docx
├── 01-活动现场.jpg
├── 02-嘉宾发言.jpg
└── 03-合影.jpg
```

有语义的图片文件名能帮助当前版本更合理地安排图片。DeepSeek `deepseek-chat` 本身不是视觉模型，所以首版不会识别图片像素内容；接入视觉模型后，可以在素材解析阶段为图片补充描述、人物和场景标签。

## 数据位置

- 任务数据：`data/tasks.json`
- 上传素材：`data/uploads/<task-id>/`

以上目录只用于本地 MVP，均不会提交到 Git。正式部署建议替换成 PostgreSQL 和兼容 S3 的对象存储。

## 当前边界

- 前端展示的是高相似度模拟预览，微信最终效果仍需在公众号后台确认。
- HTML 中的本地图片地址不能直接用于正式公众号发布。接入微信公众号后，需要先上传正文图片和封面，再调用草稿接口替换地址。
- 秀米模板目前使用自有风格模板模拟，没有抓取或自动操作秀米网站。
- 未配置公众号凭证时，“同步草稿并打开微信预览”会直接打开公众号后台，并提示需要补充配置。
